# 可信融合与反馈调节

## 独立复测

前测从确认调节开始，后测从点击“结束练习，开始复测”开始。两次各采集 30 秒，到期后默认再等 3 秒接收窗内的迟到结果。跨越边界的语段排除。结束等待、跳过或自动定稿后，普通迟到结果无法改写已定稿的观察。

每个窗口记录各模态的有效时长、平均质量和四类线索均值，同时保留联合、单视觉、单声学的时长比例及实际融合权重。前测开始时固定比较协议。单模态至少覆盖窗口的一半，前后平均质量之差最多 0.15。两边均有可比视觉与声学结果时，各占一半计算总差值。双方都是同一种单模态时按该模态比较。只有部分模态可匹配时单列其变化。协议同时检查来源独立、模型版本、会话、活动及配置指纹。

复现“前测一半仅视觉，后测全程联合”的反例及窗口到期、迟到、跳过边界，可运行 `tests/test_assessment.py` 和 `tests/test_detection_integration.py`。自评和主观帮助程度仍可在缺少辅助观察时填写。

## 选择融合策略

在“使用说明 → 两种线索怎样共同判断”中选择遵循本地设置、质量加权或使用本地校准参数。开始会话后固定这次选择。实时页显示实际执行的策略与拒识状态，权重区域的提示可查看工程质量、类别分布熵、未映射占比和校准版本。没有匹配参数时沿用质量加权。独立标注格式、拟合命令、消融指标及可靠性图见 [校准说明](CALIBRATION.md)。

## 个人参考

学习授权按会话选择。“修正当前观察”会固定打开对话框时的观察及原始事件编号。主观修正、当前困扰和打扰反馈分别记录。只有主动确认“这是我的日常状态”的反馈能成为候选参考。

应用从已结束会话中选取质量合格、覆盖充分、来源可追溯、条件一致的样本，排除活动期、冲突及后来被修订的记录。同一档案与来源下，至少 2 场会话、5 条独立样本后才显示个人比较。参考统计包括中位数、四分位区间和绝对偏差中位数。会话内使用冻结版本。暂停或重置后立即停止显示个人比较，算法配置仍保留会话开始时的版本记录。重置会清除当前档案在所选来源下的学习依据。

使用历史页导出的本地会话文件可以做按时间前推的回放。有独立标签时，下例同时统计同一批观察的错误率、用户明确标注的误提示率和反馈负担。样本不足的指标保留为空。

```powershell
.\.venv\Scripts\python.exe scripts/evaluate_personal_reference.py reports/past.json reports/later.json --labels data/reference-labels.json --out reports/personal-reference.json
```

可选的标签文件是 JSON 数组。观察标签包含 `session_id`、`event_id`、布尔值 `above_usual`。提示标签包含 `session_id`、`decision_id`、布尔值 `prompt_wanted`。

## 提示与推荐

- 主动调节随时可用。系统询问前检查有效证据、可用性和冷却。同一档案、同一来源在最近一小时内最多收到两次主动询问。拒绝后冷却 20 分钟，一小时内反复拒绝会延长暂缓。只有多段高质量联合证据持续分歧、满足有效时长和覆盖条件时，才发出可跳过的澄清。
- 调节页延用已有的需求、时间、偏好及历史排序。选定起始困扰后，页面同时显示相近需求、可用时间和起始困扰下的独立复测数。至少两条数值反馈时显示变化的样本标准差。
- 影子策略在相同候选集上按匹配情境的活动内复测变化、样本数及波动调整顺位。普通会话中它只写入决策日志；仅在主动参加[交叉对照实验](CROSSOVER_STUDY.md)且分到自适应策略时，界面才实际采用这一顺位。明确回避或有不适记录的方法先排除。缺失复测保留为空，换方法链不归因到末尾的方法。
- 导出会话的 `events` 包含提示决策及候选排序。活动的 `decision_log` 关联展示记录、后台排序、实际选择和本次活动记录。确定性排序与用户自选没有随机分配概率，故 `selection_probability` 为空。

## 语音和采集

单独授权转写后，同一语段的声学与文字结果使用相同的 `segment_id`。中文规则标记说话对象、时间、引用和明确感受。适合的需求建议短时显示，用户点击后才填入调节页。撤回转写会使语境建议和已保存的语境派生字段失效，保留此前获授权的转写原文。

真实模式可通过本地 `data/capture-config.json` 指定采样周期、队列、超时和重载次数，例如 `{"visual_period":1.0,"audio_queue":2,"max_reloads":1}`。采样间隔变长会保留观察缺口。资源事件记录各阶段延迟分位数、队龄、丢弃计数和 CPU，供相同输入下的调度对比。官方样例验证和离屏测试的结果只反映执行这些测试时的条件。
