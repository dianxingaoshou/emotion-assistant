# 中文多模态教师的缺失证据对照

在这组实验之后，使用原桌面固定 v1、emotion2vec+ 和 MiniCPM-o 音频替换做了同片对照，并复测了中性校准与保守改判。[后续教师分类头与策略实验](CHSIMS_TEACHER_REFINEMENT.md)

上一版用一个分类头处理完整输入和整路缺失，已对照缺文字、缺声音、缺画面。这一轮加入双路缺失、三路全缺以及局部缺段，检验教师能否利用剩下的证据判断整段表达。[上一版整路缺失对照](CHSIMS_OMNI_ADAPTATION.md#三路融合的整段结果)

## 输入与缺失条件

使用本地 CH-SIMS v2.0 的全部有标注视频。官方训练集 2,722 段、验证集 647 段、测试集 1,034 段，片段编号互斥。官方测试中有 190 段的 `video_id` 在训练和验证中均未出现，按来源另行统计。所有条件统一用整段人工标注 `label` 计分，大于零为正向，等于零为中性，小于零为负向。[作者数据页](https://thuiar.github.io/sims.github.io/chsims) · [CH-SIMS v2.0 论文](https://arxiv.org/abs/2209.02604)

| 条件 | 模型得到的输入 |
| --- | --- |
| 完整输入 | 自动转写、原音轨、已遮盖字幕的画面。自然缺失时按实际证据分流 |
| 整路缺失 | 移除相应通道的全部特征及可用标记。枚举三种缺一路、三种只剩一路，以及全部移除 |
| 局部丢词 | 按片段编号固定位置，从自动转写删去连续约 40% 的识别单元。汉字按字计，英文按词计。声音和画面保持完整 |
| 局部缺声音或画面 | 选片段时长的连续 40%。声音用静音覆盖该段，桌面声学模型对剩余片段重新分段。画面直接移除该区间的采样帧，并从剩余帧重新提取人脸 |
| 局部声画同时缺段 | 在同一时间区间处理中断的音轨和画面，保留已取得的完整转写 |
| 三路同步缺段 | 声画同时缺段，自动转写也从剩余音频重新生成 |

整路缺失用单路独立编码结果模拟关闭通道。局部缺段先改动输入，再重新运行对应编码器。仅画面来自静音、字幕遮盖后的采样帧，原音轨仍可听到字词。后一项意味着缺文字条件测的是独立转写不可用时的表现。[输入准备与推理脚本](../scripts/prepare_chsims_teacher_gaps.py)

## 优化方法

Parthasarathy 和 Sundaram 在 Aff-Wild2 上用整段和帧级遮蔽增强训练，改善了画面缺失时的表情与语音表达识别。Ma 等人在多模态 Transformer 实验中发现，适合缺失输入的融合策略会随数据集变化。本实验结合缺段增强与可用证据组合，在 CH-SIMS 上单独选参。[ICMI 2020](https://arxiv.org/abs/2010.00734) · [CVPR 2022](https://arxiv.org/abs/2204.05454)

1. **按可用证据选择分类头。** 文字、声音和画面构成七种非空组合，每种组合有自己的线性分类头。局部缺失造成某路完全不可用时，按剩余证据重新选择组合。三路全缺直接暂缓。
2. **让分类头见到残缺输入。** 保持 Qwen2.5-Omni-3B 编码器冻结，用完整和局部损坏的训练样本更新分类头。数据加权同时考虑情绪类别和影视来源的样本数。
3. **在验证集选择正则化与融合比例。** 按影视来源留出验证，综合准确率、Macro-F1 与各来源平均准确率选择参数，校准概率与中性分数。每种证据组合有固定的验证集融合比例，将同时使用千问和桌面特征的分类头与同训练桌面分类头加权。另按组合校准低置信度暂缓阈值。[分类头训练、评测和导出](../scripts/chsims_teacher_robustness.py)

三套方法读取同一批残缺证据。上一版教师使用原有的共享分类头。同训练桌面版使用项目已有的 Qwen3-Embedding-0.6B 文本向量、emotion2vec+ seed 的声学分数与语音向量、桌面表情分数。改进教师再加入 Qwen2.5-Omni-3B 的内部表示。两套新模型使用相同的训练与验证流程。准确率按全部测试片段计算，暂缓计入分母。Macro-F1 对负向、中性和正向等权。区间按 `video_id` 配对重采样 2,000 次。

- **整体正确率提高。** 原始输入从 74.95% 升至 77.85%，相对上一版教师纠正 51 段、改错 21 段。按来源配对的准确率差 95% 区间为 +1.44 至 +4.43 个百分点。11 种缺失条件的平均正确率在官方全集提高 3.34 个百分点，在 190 段复测组提高 3.83 个百分点，区间分别为 +2.35 至 +4.35、+1.49 至 +6.37 个百分点。全集的平均 Macro-F1 提高 0.0136，其差值区间为 −0.0011 至 +0.0268。[配对统计](results/chsims-omni-missing-evidence.json)
- **只剩一路时增益最明显。** 仅画面比上一版多判对 76 段，两版均覆盖 1,034 段。同训练桌面纯画面暂缓 417 段，所以与桌面的差异同时包含覆盖率和分类表现。未见来源的缺画面条件从 97 段提高到 114 段，与同训练桌面的 116 段接近。缺文字条件在这组从 131 降至 127 段。[各条件的完整对照](results/chsims-omni-missing-evidence.json)
- **局部缺段的中性召回仍是弱项。** 三路同步缺段时，正向召回从 236/423 升至 295/423，负向从 422/488 降至 396/488，中性从 42/123 降至 29/123。原始输入的中性召回也从 53/123 降至 40/123。局部缺段测试使用一个连续缺失比例，现场遮挡、设备断流和其他缺失比例仍待验证。[错误分布与逐类召回](results/chsims-omni-missing-evidence.json)

单独启用验证集选出的暂缓阈值时，三路同步缺段的已判准确率从 69.63% 提高到 71.80%，覆盖率降至 93.62%，判对数为 695 段。这组读数适合在应用中衡量错判与暂缓的取舍。[覆盖率对照](results/chsims-omni-missing-evidence.json)

## 原桌面 emotion2vec+ 的纯声音对照

## 核验与训练监督

统一桌面对照的特征提取版本后重新拟合。抽查 72 段音轨和帧缺口，再用当前脚本重新处理 24 段，核对输入和语音向量。用 scikit-learn 独立复算了 130 组条件、模型和测试范围的准确率、Macro-F1、召回、混淆矩阵和暂缓数，并重现了旧实验的 16 项混淆矩阵。项目离屏回归通过 651 项。

改进教师以离线训练监督的方式运行。将训练片段按 `video_id` 分成五折，每一折使用其他来源拟合的分类头生成三类概率。已为 2,722 段训练片段导出 32,637 组三类概率，保存在 `.runtime/chsims-teacher/full/missing-evidence/training-targets.json`。输出记录每段、每种缺失条件中的可用通道，三路均缺时结果为空。这份概率可以供后续学生模型训练。[训练监督导出代码](../scripts/chsims_teacher_robustness.py)

## 本地复现

在项目根目录使用已准备的 CUDA 教师环境和桌面环境。先完成全量证据缓存及上一版教师对照，再运行缺失实验。中间缓存与分类头输出位于 `.runtime/chsims-teacher/full/missing-evidence`。[全量缓存准备](CHSIMS_OMNI_TEACHER.md#复现全量监督) · [原教师对照的复现指令](CHSIMS_OMNI_ADAPTATION.md#复现与文件位置)

```powershell
$data = 'D:\情绪数据集\ch-sims2s\ch-simsv2s'
$teacher = '.\.runtime\chsims-teacher\venv\Scripts\python.exe'
$desktop = '.\.venv\Scripts\python.exe'
$gap = 'scripts/prepare_chsims_teacher_gaps.py'
$study = 'scripts/chsims_teacher_robustness.py'

& $teacher -B -X utf8 $gap prepare --data $data --device cuda
& $teacher -B -X utf8 $gap encode --data $data --batch-size 4
& $desktop -B -X utf8 $gap desktop --data $data
& $desktop -B -X utf8 $study fit
& $desktop -B -X utf8 $study evaluate --output docs/results/chsims-omni-missing-evidence.json
& $desktop -B -X utf8 $study export
& $desktop -B -X utf8 scripts/compare_chsims_original_audio.py --output docs/results/chsims-original-audio-comparison.json
```
