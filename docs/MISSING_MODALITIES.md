# 缺失输入下的识别与文件检测

本次升级解决两个实际问题：同一段视频里声音与画面可能只在部分时段有效，上传文件还可能带有剪辑偏移或根本没有某一路。实时与文件检测共用时段判断和校准参数。下面的结果均由本项目运行得到。

## 可以怎样用

| 输入 | 可以查看的结果 |
| --- | --- |
| 实时摄像头、麦克风 | 当前时段可用的通道、声画分歧、质量权重和判断依据。一方缺失时继续处理另一方。只有本人确认后才开始调节活动。 |
| 照片或无声视频 | 人脸框、单帧八类表情，以及通过质量检查后的四类线索。长视频的抽样间隔会增大，最多 240 帧。 |
| 有声视频或独立音频 | 以媒体显示时间戳对齐人声和画面，逐时段标明双路、单路或暂缓。声音重采样到 16 kHz 并按人声分段；已知时长超过 120 秒时分 12 个窗口抽样，合计最多 120 秒。 |
| 单独提供文本或勾选音视频转写 | 中文可生成待本人确认的语境提示。英文发言可查看极性与表达强度，有同期声画时还可查看极性联合试算。文件极性按有效时长汇总。符合条件的短英文音视频用整段转写的词与字符特征估计强度，其余沿用逐发言结果。 |

在“本地文件检测”选择文件即可，无需开启设备。照片和视频左侧显示原始抽样画面及模型检测框；右侧汇总有分数的时段，并单列暂缓次数。在时段列表中可查看同一类别在移除画面或声音后的分数。所有时段都暂缓时，界面不显示整段主分类。导出 JSON 时保留详细模型输出和决策；选中文本文件或授权转写时，导出也包含这些文字。

## 怎样处理缺失和解释判断

1. **对齐证据。** 对音视频独立解码，采用同一个文件时间原点。按实际重叠时段融合，不把一开始的声音搬到结尾的画面上。视频剪辑用显示时间戳处理，避免将容器给出的总帧数误当作有效时长。
2. **按可用通道预测。** 只有通过输入质量与覆盖检查的通道才参加该时段判断。仅一路有效时，使用在同模型版本、同类标注上拟合的四类分数校准。缺少匹配参数时保留该通道原分数。完整双路沿用已有策略；如果用户已有匹配的自定义融合校准，优先使用其设置。两路都缺、分歧明显等情况会记录暂缓原因。
3. **用同一函数重算依据。** 固定该时段及原预测的目标类别，分别去掉画面、声音，重新执行同一套判断，包括单路校准。界面中的分数差表示该输入对本次输出有何影响。只有一路时，去掉它就没有可用分数，导出保留空值。权重、原始分数与重算结果分别记录。
4. **区别声音和语言。** 声学通道使用说话声音。英文文本模型使用词与相邻词对。系统分别展示声画线索与发言内容倾向，后者支持把同一句话的文字和可用声画结合试算。转写默认关闭。缺少文字不影响声画评分，短文本、超出词汇覆盖或分数不足时可以暂缓内容判断。[三路试算和启用条件](CONTENT_FUSION.md)

参考项目在 CMU-MOSEI 上研究词级对齐、分任务风险融合及同函数归因。本项目借鉴可用性标记、连续缺失实验和移除输入后复算的方法。桌面端执行时段级声画融合、单通道校准，并以整次发言为单位做三路内容试算。当前对齐精度为发言时段级，内容目标为三类倾向。下列数字来自桌面项目的实际运行。[参考仓库](https://github.com/JavenQvQ/cumcm-2026-problem-e) · [参考方法与缺失定义](https://github.com/JavenQvQ/cumcm-2026-problem-e/blob/main/docs/q2/建模与实验.md) · [参考归因定义](https://github.com/JavenQvQ/cumcm-2026-problem-e/blob/main/docs/q3/归因定义与推导.md)

## 实测一：表情或声音缺失

RAVDESS 的拟合、策略选择、测试各用 8 名不同演员。以下在相同的 62 条留出片段上比较，参照为 10 位观察者对完整视听表演投票所得的四类标签。表中准确率按模型最高类别计，自动提示另有接受门槛。单路参数仅根据拟合和策略选择集确定。[数据与既有实验设计](RECOGNITION_EXPERIMENT.md)

| 条件 | 升级前准确率 | 升级后准确率 | 变化的来源 |
| --- | ---: | ---: | --- |
| 完整双路 | 93.55% | 93.55% | 此条件沿用双路策略 |
| 声音全部缺失，仅画面 | 48.39% | 70.97% | 对幸存视觉分数做四类校准 |
| 画面全部缺失，仅声音 | 98.39% | 95.16% | 出现 2 个额外错例 |
| 声学质量降为原来的四分之一 | 56.45% | 80.65% | 39 段仅剩视觉，23 段仍能双路判断 |
| 视觉覆盖降为一半 | 98.39% | 98.39% | 14 段仅剩声音 |
| 两路均缺失 | 62/62 暂缓 | 62/62 暂缓 | 无有效证据时不输出类别 |

仅视觉时，Macro-F1 从 0.4447 升至 0.7010，Brier 概率误差从 0.6309 降至 0.4166；按演员配对重抽，误差差值的 95% 区间为 −0.2890 至 −0.1375。通过决策门槛的片段从 61 降至 51，接受的错误从 32 降至 15。降低质量或覆盖的两行是在提取证据后调整输入，不等同于重新录制噪声音频。[逐条件统计与原始分母](results/missing-modality-benchmark.json)

**连续缺一段的实测。** 对同一批原始 MP4，分别在开头、中间、末尾移除 25% 或 50% 的画面或声音。音频缺口两边的真实波形分开重新推理；视觉按实际帧时间移除。两个版本共用保留下来的输入、时间窗与汇总方式。这项实验用原片定义的发声片段测试缺口，不包含线上语音活动检测的误差。

| 连续缺失类型 | 配对条件数 | 升级前准确率 → 升级后 | 四类 Macro-F1 之前 → 之后 |
| --- | ---: | ---: | ---: |
| 缺声音 | 372 | 57.80% → 82.26% | 0.5688 → 0.8190 |
| 缺画面 | 372 | 97.58% → 97.04% | 0.9757 → 0.9702 |
| 两类条件合计 | 744 | 77.69% → 89.65% | 0.7853 → 0.8966 |

744 次来自 62 段视频各重复 12 种条件。模型给出分数的时间覆盖前后均为 98.70%。真实改进主要发生在声音缺失、需要依赖视觉的时候。[各位置、长度及连续缺失结果](results/continuous-gaps.json)

## 实测二：E 题原视频与英文文本

**原始文件导入。** 将附件 1 的 100 段英文原片全部送入文件入口。37 个源视频，整段人工标签为 57 正、25 中、18 负。下表关闭转写，按整段声画汇总最高项计分，无分数或最高为未映射均计错。基线保存了升级前的逐片输出及原始媒体 SHA256。

| 方法 | 有模型分数 | 与整段人工标签一致 | 三类 Macro-F1 |
| --- | ---: | ---: | ---: |
| 升级前本地文件入口 | 12/100 | 5/100 | 0.0846 |
| 仅修正解码后，取同一批画面的原视觉平均 | 74/100 | 18/100 | 0.1697 |
| 新版文件入口，允许结合声音 | 94/100 | 25/100 | 0.1861 |

其中 68 段用到了声画两路，24 段仅声音，2 段仅画面，6 段没有分数。94 个有分数的结果中，88 个最高项属于三种已映射类别。两种新版方法都能给分的 74 段均判对 18 段；新增正确数来自声音补足原先无有效画面的片段。相对修正解码的纯视觉方法，准确率差为 +7 个百分点，按源视频配对重抽的 95% 区间为 −7.1 至 +22.6 个百分点。该批片段恒猜正向可得 57/100，**单靠声画不足以稳定判断这批英文发言的语义倾向**。[逐片审计、区间与准确率](results/mosei-upload.json)

**只给英文文字。** 附件 2 的 3,395 条训练转写用于拟合三类模型。728 条验证转写、727 条测试转写独立评价，各集合源视频互不重叠。测试中 706 条有预测，将另外 21 条计为错误后，准确率为 52.68%、Macro-F1 为 0.4956；训练集多数类基线分别为 49.79% 和 0.2216。中性仅召回 47/158（29.75%）。此处用的是提供的文字，文件自动转写还受噪声、口音和分段影响。[测试混淆矩阵与模型版本](results/english-polarity.json)

**从上传视频的声音生成文字。** 附件 1 全部 100 段原片中有 96 段取得实际转写。为防止英文分类器在训练或验证时接触同源发言，排除重叠源视频后，用其余 19 个源的 43 段评价。有 42 段取得转写、37 段给出文本极性。三种方法均以同一批 43 段为分母，未给分计错。

| 同一批 43 段的英文内容倾向 | 准确率 | 三类 Macro-F1 |
| --- | ---: | ---: |
| 视频 → 实际自动转写 → 英文模型 | 19/43（44.2%） | 0.318 |
| 视频对应的官方文字 → 同一英文模型 | 22/43（51.2%） | 0.449 |
| 恒猜训练集的多数类正向 | 27/43（62.8%） | 0.257 |

自动转写链路的 Macro-F1 高于多数类基线，准确率较低。这 43 段不能与附件 2 测试集相加当作独立样本。[自动转写端到端评估、来源去重与分母](results/mosei-asr.json)

## 复验

缺失输入功能首次验收时通过 356 项回归，`scripts/verify.py` 离屏验收通过。另经真实桌面控件依次选择人像照片、有声 MP4、独立 WAV、授权转写的 MP3 和 TXT，检查实际模型结果及 JSON 导出。上述文件流程未打开摄像头或麦克风。自动测试还覆盖音轨晚于画面两秒、可变帧率、部分画面解码中断、缺模型、无语音及取消。

从项目根目录运行。声画实验需已安装本地模型；RAVDESS 原片和评分的准备步骤见[原实验说明](RECOGNITION_EXPERIMENT.md)。E 数据保持在用户原目录中，结果文件仅保存指标和审计标识。

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/benchmark_missing_modalities.py --report reports/missing-modality-rerun.json
.\.venv\Scripts\python.exe scripts/benchmark_local_gaps.py --report reports/continuous-gaps-rerun.json
.\.venv\Scripts\python.exe scripts/benchmark_mosei_upload.py --data "本机的E题数据目录" --out reports/mosei-upload-rerun.json
.\.venv\Scripts\python.exe scripts/benchmark_mosei_asr.py --data "本机的E题数据目录" --out reports/mosei-asr-rerun.json
.\.venv\Scripts\python.exe scripts/fit_english_polarity.py "附件2-数据集特征文件/label.xlsx" --model reports/english-polarity-rerun.json.gz --report reports/english-polarity-rerun.json
```
